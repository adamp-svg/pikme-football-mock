## Files

- `concept-sheet-20.png` — full 5-by-4 comparison sheet.
- `pairs/01-pair.png` through `pairs/20-pair.png` — cropped Play + Shop
  comparisons.
- `stills/` — 256px source stills for concepts 08, 16, 18, 19, and 20.
- `animated/` — looping 256px GIFs for Play and Shop in those five
  effects-driven styles. Each loop uses a restrained shine sweep, brightness
  pulse, sparkle pass, and idle hold.

The pair crops retain their dark presentation background. Before production
integration, the selected direction should be redrawn/exported with a
transparent background at the game's exact rendered sizes.
