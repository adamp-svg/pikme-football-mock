# Expansion usage instructions

## Future game systems

| Asset | Use |
| --- | --- |
| `goalkeeper` | Role picker, goalie card, keeper training, or keeper stats. |
| `striker` | Attacking role, striker card, or shooting specialization. |
| `defender` | Defensive role, marking specialist, or defender card. |
| `formation` | Team-shape editor, lineup, or tactical preview. |
| `ranked-event` | Competitive queue or time-limited ranked event. |
| `daily-challenge` | One-day rotating objective. |
| `quest` | Multi-step or longer-lived objective list. |
| `achievement` | Permanent accomplishment; do not use for temporary quests. |
| `replay` | Saved-match replay or replay viewer. |
| `spectate` | Live viewing without participating. |
| `rematch` | Re-enter a match with the same players. |
| `matchmaking` | Searching for opponents or assembling a public room. |
| `private-room` | Invite-only or code-protected match. |
| `voice-chat` | Voice channel availability, mute controls, or headset state. |
| `club-war` | Club-versus-club match series or seasonal club conflict. |
| `training-drill` | Structured cone/skill practice rather than free training. |

## Future account and progression

| Asset | Use |
| --- | --- |
| `profile` | View the current or another player’s profile. |
| `edit-profile` | Change name, portrait, banner, or profile settings. |
| `inbox` | System messages, gifted rewards, and administrative notices. |
| `event-calendar` | Upcoming events and scheduled tournaments. |
| `leaderboard` | Ranked list or podium view. |
| `player-stats` | Personal performance statistics and trends. |
| `match-history` | Previous match result list and drill-down. |
| `season-road` | Visual season milestones and reward progression. |
| `reward-chest` | Closed chest or unopened earned reward. |
| `key` | Chest key or gated-unlock currency. |
| `claim` | A reward is ready to collect. |
| `upgrade` | Improve a card, power, hero, or ability. |
| `merge` | Combine duplicates into one improved item. |
| `favorite` | Pin or favorite a card, field, mode, or player. |
| `report-player` | Safety report flow; never use for normal warnings. |
| `block-player` | Stop invitations and communication from a player. |

## Social emotes

| Asset | Use |
| --- | --- |
| `emote-wave` | Friendly greeting at lobby or kickoff. |
| `emote-thumbs-up` | Encouragement and approval. |
| `emote-clap` | Praise a specific play. |
| `emote-heart` | Friendly support or appreciation. |
| `emote-good-game` | Sportsmanship after a match. |
| `emote-sorry` | Apologize for a missed pass, own goal, or mistake. |
| `emote-thanks` | Thank a teammate for help or a pass. |
| `emote-celebrate` | Celebrate a positive moment without taunting. |
| `emote-laugh` | Playful laughter; rate-limit to reduce taunting. |
| `emote-wow` | React to an impressive or surprising play. |
| `emote-sad` | Express disappointment. |
| `emote-angry` | Express frustration; rate-limit and make muteable. |
| `emote-confused` | Signal confusion without blaming a player. |
| `emote-nervous` | React to pressure or a close call. |
| `emote-fire` | Hype a hot streak or excellent play. |
| `emote-mvp` | Praise the standout player. |

## Tactical calls

| Asset | Use |
| --- | --- |
| `call-pass` | Request the ball or announce a pass. Team-only during play. |
| `call-shoot` | Tell the ball carrier to shoot. |
| `call-defend` | Ask the team to protect its goal. |
| `call-attack` | Ask the team to push forward. |
| `call-left` | Move play toward screen/field left. |
| `call-right` | Move play toward screen/field right. |
| `call-wait` | Hold position or delay the action. |
| `call-ready` | Signal readiness for kickoff or a set play. |
| `call-help` | Ask the nearest teammate for support. |
| `call-mark` | Ask a teammate to cover an opponent. |
| `call-goalkeeper` | Coordinate goalkeeper position or goal coverage. |
| `call-spread` | Create width and separate from teammates. |
| `call-group` | Regroup around the ball or objective. |
| `call-retreat` | Fall back and rebuild defensive shape. |
| `call-rematch` | Request another game after the result. |
| `call-well-played` | Praise a tactical team action. |
