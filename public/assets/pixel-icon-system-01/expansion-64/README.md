# Saltiz Pixel Icon Expansion 64

This extends Graphic Language 01 from 96 to **160 total semantic assets**.

- 32 future-facing product/game icons
- 16 social and emotional player emotes
- 16 tactical player calls

## Files

- `sheets/` — four review sheets, 16 assets each.
- `tiles/` — named 256px presentation tiles.
- `transparent/` — named 256px alpha PNGs.
- `manifest.csv` — stable IDs and intended use.
- `EXPANSION_USAGE.md` — per-asset instructions.
- `COMMUNICATION_SET.md` — recommended player-emote behavior and wheels.
- `sprite-pack-160.webp` — optional combined 160-asset pack.
- `sprite-pack-160.png` — lossless combined source.
- `labeled-expansion-64.png` — alphabetical labeled catalog.
- `giant-atlas-160.png` — all ten sheets in one review atlas.

The 160-pack order is the original `manifest.csv` assets first, followed by
this expansion manifest. It is not wired into the live game until the new
features and emote picker are approved.
